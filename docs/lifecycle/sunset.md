# Sunset · P2

Retire a capability or service with clear notice and a safe path for user data.
Run this before any shutdown, even if the product never reached broad adoption.

## Checklist and proof

- [ ] Define what ends, who is affected, and the proposed final dates.
  Proof: the retirement issue lists clients, integrations, contracts, and owners.
- [ ] Inventory live traffic, installed mobile clients, scheduled jobs, and billing.
  Proof: dashboards and provider inspections identify remaining consumers.
- [ ] Plan user notice, support coverage, and alternatives.
  Proof: draft messages state dates, user actions, export options, and contacts.
- [ ] Build and rehearse export for data users are entitled to keep.
  Proof: a test account can retrieve and open a complete, documented export.
- [ ] Agree retention, legal holds, backup expiry, and deletion order.
  Proof: the founder-approved plan names stores and dates, including processors.
- [ ] Stop new signups and purchases at the agreed point.
  Proof: staging checks reject new commitments while existing users can exit.
- [ ] Reconcile subscriptions, refunds, invoices, and provider billing shutdown.
  Proof: sandbox rehearsal and redacted provider reports show the intended state.
- [ ] Plan mobile listing removal and behavior for installed clients.
  Proof: a test old client displays useful notice and fails safely after shutdown.
- [ ] Disable integrations, credentials, queues, and infrastructure in safe order.
  Proof: the plan gives per-step checks and a recovery window before deletion.
- [ ] Verify deletion and provider termination after authorized execution.
  Proof: provider confirmations and access checks match the approved inventory.
- [ ] Archive code and decisions, preserving only the agreed retained records.
  Proof: archive location, access owner, retention date, and support endpoint exist.

## Founder handoff

Apply the [authority rule](README.md#evidence-and-authority). The founder approves
the retirement decision, notices, legal/contract obligations, refunds, store
changes, production shutdown, and every non-local deletion. Draft and rehearse
first; obtain authorization for the exact irreversible steps and dates.

## Exit

- [ ] Confirm no user-facing promise or recurring charge remains unowned.
  Proof: the founder signs off the final inventory and residual obligations.
